プライバシーポリシー

Retention Report（以下「本ツール」）は、運営者が自分の YouTube チャンネルの分析に使う個人用ツールです。

  • 本ツールは、Google の許可画面で認可されたチャンネルについて、YouTube Data API と YouTube Analytics API から読み取り専用（youtube.readonly / yt-analytics.readonly）でデータを取得します。
  • 取得したデータは運営者のパソコンの中だけに保存し、レポートの作成にのみ使います。第三者への提供・販売・広告への利用はしません。
  • 認可は Google アカウントの「サードパーティのアクセス」からいつでも取り消せます。
  • 本ツールによる Google API から受け取った情報の使用は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシーに準拠します。

Privacy Policy

Retention Report is a personal tool used by its operator to analyze the operator's own YouTube channels. It requests read-only access (youtube.readonly, yt-analytics.readonly) to the channels authorized on Google's consent screen. Data is stored only on the operator's computer and used only to create private reports. It is never shared, sold, or used for advertising. Access can be revoked at any time from your Google Account's third-party access settings. Retention Report's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
